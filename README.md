# Readee

**See. Hear. Be Independent.**

Readee is a voice-first helper app prototype for blind and low-vision students. It includes a talking "Readee Bird" voice buddy, object recognition, text reading, scan history, and settings.

## Run it
Open the live page (GitHub Pages): `https://<your-username>.github.io/<repo-name>/`

Demo login: username `student`, password `readee123`.

## Notes
- Use Chrome or Edge for the best voice support.
- Allow microphone and camera access when asked. On the GitHub Pages (HTTPS) link, the browser remembers your choice.
- Smart mode is optional: paste an Anthropic API key in Settings. The key is stored only in your browser.
